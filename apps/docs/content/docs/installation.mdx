## Prerequisites

- **Node.js** 18 or later
- **React** 19
- **Vite** 6, 7, or 8

## Install

<Tabs items={["pnpm", "npm", "yarn", "bun"]}>
	<Tab value="pnpm">
		```bash pnpm add @sundayceo/framework react react-dom pnpm add -D vite @types/react
		@types/react-dom typescript ```
	</Tab>
	<Tab value="npm">
		```bash npm install @sundayceo/framework react react-dom npm install -D vite @types/react
		@types/react-dom typescript ```
	</Tab>
	<Tab value="yarn">
		```bash yarn add @sundayceo/framework react react-dom yarn add -D vite @types/react
		@types/react-dom typescript ```
	</Tab>
	<Tab value="bun">
		```bash bun add @sundayceo/framework react react-dom bun add -D vite @types/react
		@types/react-dom typescript ```
	</Tab>
</Tabs>

## Project structure

<Steps>
<Step>
### Create your source directory

```
src/
├── app.ts              # App config + context factory
├── templates/
│   └── default.tsx     # Page template with slots
├── routes/
│   └── index.tsx       # Home page
└── styles.css          # (optional) Global styles
```

</Step>

<Step>
### Configure Vite

```ts title="vite.config.ts"
import { defineConfig } from "vite";

import { frameworkPlugin } from "@sundayceo/framework/vite";

export default defineConfig({
	plugins: [frameworkPlugin()],
});
```

</Step>

<Step>
### Configure TypeScript

```json title="tsconfig.json"
{
	"compilerOptions": {
		"target": "ES2022",
		"module": "ESNext",
		"moduleResolution": "bundler",
		"jsx": "react-jsx",
		"strict": true,
		"noEmit": true,
		"types": ["node"]
	},
	"include": ["src"]
}
```

</Step>
</Steps>

## Generated files

When you run the dev server or build, the Vite plugin generates two files in `src/`:

| File                 | Purpose                                                                                  |
| -------------------- | ---------------------------------------------------------------------------------------- |
| `framework.gen.d.ts` | Type declarations for `TemplateRegistry`, `RouteMap`, and `Register`                     |
| `routes.gen.ts`      | Route manifest with lazy imports, template registry, error pages, and hydration manifest |

<Callout type="info">
	These files are auto-generated. Add them to `.gitignore` or commit them — either approach works.
	They're regenerated on every build and dev server start.
</Callout>

## Package exports

The framework ships four entry points:

| Import                              | Purpose                                                                |
| ----------------------------------- | ---------------------------------------------------------------------- |
| `@sundayceo/framework`              | Runtime API — `createApp`, `definePage`, `defineHandler`, `Slot`, etc. |
| `@sundayceo/framework/vite`         | Vite plugin — `frameworkPlugin`                                        |
| `@sundayceo/framework/codegen`      | Codegen API — `codegen`, `generateServerEntry`                         |
| `@sundayceo/framework/server-entry` | Virtual module — the generated server handler                          |
