## redirect

Creates a `RedirectResponse` that can be thrown to redirect the client.

```ts
function redirect(url: string, status?: number): RedirectResponse;
```

| Parameter | Type     | Default | Description               |
| --------- | -------- | ------- | ------------------------- |
| `url`     | `string` | —       | The URL to redirect to    |
| `status`  | `number` | `302`   | HTTP redirect status code |

### Usage

```ts
import { redirect } from "@sundayceo/framework";

loader: ({ params }) => {
  if (params.slug === "old-post") {
    throw redirect("/blog/new-post");
  }
  // Permanent redirect
  throw redirect("/new-url", 301);
},
```

## httpError

Creates an `HttpErrorResponse` that can be thrown to return an HTTP error.

```ts
function httpError(status: number, message?: string): HttpErrorResponse;
```

| Parameter | Type     | Default                 | Description            |
| --------- | -------- | ----------------------- | ---------------------- |
| `status`  | `number` | —                       | HTTP error status code |
| `message` | `string` | `"HTTP Error {status}"` | Error message          |

### Usage

```ts
import { httpError } from "@sundayceo/framework";

loader: ({ params }) => {
  if (!params.slug) {
    throw httpError(400, "Missing slug parameter");
  }
  throw httpError(404, "Post not found");
},
```

When thrown, the framework catches the error and renders the corresponding [error page](/docs/guides/error-pages) (if one exists) or falls back to a minimal HTML response.

## Type guards

### isRedirectResponse

```ts
function isRedirectResponse(error: unknown): error is RedirectResponse;
```

### isHttpErrorResponse

```ts
function isHttpErrorResponse(error: unknown): error is HttpErrorResponse;
```

These are useful when implementing custom error handling logic.
